# AI_Chatbot

# 🌙 Supper Chatbot: KL Night Market Assistant

**Module:** Introduction to Artificial Intelligence 

## 📘 Project Overview

This project focuses on the design and implementation of an AI-powered conversational agent, the **Supper Chatbot**, developed as part of our coursework for the **Introduction to Artificial Intelligence** module. 

The Supper Chatbot is designed to provide both locals and tourists with an autonomous, interactive interface to explore Kuala Lumpur’s vibrant night markets. By leveraging Natural Language Processing (NLP) and structured knowledge representation, the chatbot acts as a 24/7 virtual guide, offering personalized market recommendations, details on local cuisine (like satay and apam balik), and specific transportation routes.

## ✨ Key Features & Technologies

The chatbot was built to prioritize user experience and accuracy, utilizing the following core components:
*   **Natural Language Processing (NLP):** Processes complex human language, allowing users to communicate naturally rather than relying on strict, predefined commands.
*   **Interactive UI:** Utilizes clickable options and buttons to streamline navigation, reduce typing time, and minimize misinterpretations.
*   **Rich Media Integration:** Provides helpful visual elements (images of food and locations) natively within the chat to enhance user understanding without external plugins.
*   **Knowledge Representation:** Built using **Semantic Networks** to effectively map out hierarchical relationships between night markets, amenities, and transit options.
*   **Development Stack:** Conceptualized using **Draw.io** (for flowcharts and semantic mapping) and deployed via **Chatfuel** directly onto **Facebook Messenger**.

## 📚 Project Description

Kuala Lumpur's night markets are a major attraction for millions of tourists annually. However, navigating the sheer volume of options, understanding local delicacies, and figuring out public transit can be overwhelming. The Supper Chatbot addresses this gap by instantly aligning user preferences with tailored suggestions.

Throughout the development lifecycle, we employed comprehensive flowcharts to design logical decision-making paths and semantic networks to manage the chatbot's knowledge base. To ensure high accuracy, the bot is programmed to dynamically ask follow-up clarification questions if a user inputs incomplete keywords, preventing incorrect assumptions and ensuring highly personalized, relevant results.
